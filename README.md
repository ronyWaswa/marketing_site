# [Your Business Name] Marketing Website

A five-page marketing website built with HTML and CSS. It presents a marketing agency, its services, its work and how to contact it.

**Live site:** https://ronywaswa.github.io/marketing_site/

## Pages
- **Home** (`index.html`): introduction, main services and key figures
- **Services** (`services.html`): the marketing services offered
- **Portfolio** (`portfolio.html`): examples of past projects and results
- **About** (`about.html`): the company story and team
- **Contact** (`contact.html`): enquiry form

All pages are linked through a shared navigation menu and footer.

## Features
- Five interlinked pages
- Responsive layout that works on phones, tablets and computers
- Contact form connected to Formspree
- Shared stylesheet (`style.css`) for a consistent design

## Technologies
- HTML5
- CSS3
- Formspree (contact form)
- GitHub Pages (hosting)

## How to run locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Install the **Live Server** extension
